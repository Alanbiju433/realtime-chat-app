# 💬 Realtime Chat App

A real-time web-based chat application built with Node.js and vanilla JavaScript, allowing users to send and receive messages instantly in a shared chat room.

## 🚀 Live Demo

[View Live](https://alanbiju433.github.io/realtime-chat-app)

## ✨ Features

- Real-time messaging between users
- Persistent message history stored in `messages.json`
- Clean and responsive UI
- View full message history on a dedicated page
- Lightweight — no frameworks, just vanilla HTML, CSS, and JS

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML / CSS | Frontend UI |
| JavaScript | Client-side logic |
| Node.js | Backend server |
| JSON | Message persistence |

## 📁 Project Structure

```
realtime-chat-app/
├── index.html          # Main chat interface
├── view-messages.html  # Message history viewer
├── script.js           # Client-side chat logic
├── server.js           # Node.js backend server
├── styles.css          # Styling
└── messages.json       # Stored messages
```

## ⚙️ Setup & Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Alanbiju433/realtime-chat-app.git
   cd realtime-chat-app
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the server
   ```bash
   node server.js
   ```

4. Open your browser and go to `http://localhost:3000`

## 📌 Usage

- Open the app in your browser
- Enter your name and start chatting
- All messages are saved and viewable on `view-messages.html`
